## Soloist as an audio source

- Choose Soloist as its own audio source in Settings, next to Spotify and YouTube Music.
- Pick its streaming quality: High (160 kbps), Very high (320 kbps) or Lossless, which falls back to 320 kbps when the plan has no lossless.
- See the format Soloist is playing, such as FLAC at 44.1 kHz, in Settings.
- Switch sources mid-song and carry on from the same place, with no silence in between.
- Show Soloist as this computer in the device list instead of as a separate speaker.

## Faster navigation

- Open pages on the next frame after a click. Moving between Home, the library and playlists no longer stalls the window.
- Load each page's code in the background once the app is idle, and start fetching a page's data when the pointer rests on its link.
- Run the card and row hover and press effects in the browser instead of in script, with the same motion.
- Keep Home alive between visits instead of rebuilding it each time.

## Faster starts and page opens

- Show Home's saved feed straight away instead of waiting for the playback session to connect. Home fills in about a second after launch.
- Open albums, artists, podcasts, profiles and Spotify-made playlists from their saved copy, and refresh them in the background. A page updates in place only when Spotify's data changed.
- Show the first Home recommendations of a launch from a set prepared during the previous one.
- Build the home shortcuts from Spotify's home feed.

## Smoother playback

- Use less CPU while playing: resample in larger batches, feed audio outputs directly, stop polling the output device while stopped, and stop resending an unchanged Discord status.
- Move the progress bar a pixel at a time instead of redrawing it every frame.
- Open and close the immersive view without repainting the rest of the window.

## Fixes

- Show every liked song in the library. Only the first 200 appeared, even though the count included all of them.
- Play every liked song from the Liked Songs tile on Home, not just the first 100.
