## Spotify sign-in

- Open ncspot and Spotify desktop consent pages in sequence. Copied sign-in links still work in either order.
- Prevent idle browser preconnections from blocking the approval callback indefinitely.
- Keep manual links available if the browser cannot open a consent page.

## Library stability

- Keep concurrent library sync futures on the heap to reduce native stack use.
- Remove the fixed 96 MB JavaScript heap limit from Windows WebView2.
- Respect Spotify's rate-limit cooldown across requests instead of retrying every library section independently.
- Report incomplete syncs as errors and retain cached library data when a request fails.
- Add native Windows regression tests for consent sequencing, idle callbacks, database sync, and rate-limit recovery.
