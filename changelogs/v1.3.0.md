## Interface

- Redesigned the home, library, search, album, artist and playlist pages.
- Reworked the title bar, sidebar, player bar, device picker, cards, grids, menus and dialogs. Replaced Lucide with Musique's own icons.
- Added search in the top bar. Ctrl/Cmd+K focuses it; arrow keys navigate the results. Songs, albums, artists and podcasts appear in the dropdown.
- Added app zoom from 67% to 200%, with keyboard shortcuts and a setting that survives restarts.
- Added a sidebar mode that lists your playlists instead of just pinned items, and improved the collapsed sidebar.
- Added artwork-based ambient colors. Immersive mode and the title bar use the same palette, and Canvas videos can drive the background colors.
- Added moving blurred backgrounds in immersive mode, with a setting to turn the motion off.
- Reworked the right panel animation so pages and grids resize as it opens. Album and playlist headers now respond to the page width.
- Fixed inconsistent artwork alignment, sidebar spacing, scrollbar placement and popover edges.
- Removed hardcoded blue and green highlights from controls so they follow the selected theme.
- Updated pin and share buttons, tooltips, notifications and the update dialog. Prevented accidental text selection outside inputs.
- Added keyboard navigation and focus handling for menus and dialogs.

## Playback and discovery

- Free Spotify accounts can now play music through YouTube Music. Track information, library data and lyrics still come from Spotify.
- Premium accounts can choose Spotify or YouTube Music as the audio source in Settings.
- Added automatic YouTube track matching, a source indicator and a dialog to replace an incorrect match.
- Fixed playback cancellation and stale audio after switching tracks or audio sources.
- Added a local taste profile built from plays, completed listens and skips. Recommendations favor recent releases and artists you listen to, with fewer repeats from your existing library.
- Added Spotify's personalized home shelves, including Made for You mixes.
- Added Spotify radio and autoplay recommendations, with local recommendations as a fallback.
- Music played through Spotify in Musique now reports listening events for Spotify's recently played history.
- Added live Connect device updates and controls for a remote device's queue, shuffle and repeat.
- Added buffered audio output to reduce playback stuttering. Seeking and manual track changes clear the buffer; normal track endings keep the remaining audio.

## Lyrics

- Added word-by-word highlighting and a shared renderer for the lyrics panel and immersive mode.
- Added Apple Music, Musixmatch, QQ Music, Kugou, AMLL, BetterLyrics and Spotify lyric providers alongside LRCLIB and NetEase.
- Added recording checks using duration, title, artist and ISRC where available. Lyrics from a different recording are rejected before alignment.
- Added alignment checks when combining line and word timings from different providers.
- Added separate lead and backing vocals, duet lines, translations and romanization. Fixed sublyrics appearing on the wrong side.
- Removed generated word timings for sources that only provide line timings.
- Lyric timing now accounts for measured audio output latency rather than relying on a fixed manual offset.
- Added caching for provider results and aligned lyrics. Concurrent requests share lyric upgrades instead of repeating the same work.

## Library and artists

- Added saving and removing albums from the library.
- Added playlist editing for names, descriptions and public, private or collaborative visibility.
- Added nested playlist folders in Spotify's order and support for opening Spotify-made playlists.
- Added user profiles with public playlists, recently played artists, followers, following and follow controls.
- Added song credits with performers, writers, producers and source information where available.
- Added artist biographies, photos, related artists, appearances, compilations, monthly listeners, top cities and world rankings where available.
- Added artist tour dates, merchandise and external links.
- Added Canvas videos in immersive mode, with a setting to disable them. The blurred background now follows the video directly.
- Added local listening stats for the week, month, year or all time: listening time, top songs, artists and albums, genres, streaks and an activity heatmap. The stats page can be hidden in Settings.
- Removed the genre browser. The audiobook pages added during development were also removed before this release.

## Podcasts

- Added podcast search, show pages, episode lists and saved shows.
- Added playback speed control and skip buttons. The chosen speed is remembered for podcasts; music always plays at normal speed.
- Added an immersive podcast view with episode notes, synced transcripts and video previews where available.
- Podcasts can play from a show's public RSS feed or a matching YouTube upload when using the YouTube Music source. Spotify exclusives without a public source cannot play through it.
- Fixed podcast controls disappearing after playback started, low-resolution covers and lag in the transcript panel.

## Friends and Jams

- Added a Friends panel showing what people you follow are playing, with a setting to hide it.
- Added Spotify Jams: start a session, join through an invite link, share the link and leave or end a session.
- Added participant lists, host controls to remove members and a choice between queue-only access and playback control.
- Reworked Jam playback and queue synchronization with Spotify Connect. Jams require the Spotify audio source.
- Fixed Jam invite links so they can be shared outside Musique.

## Fixes and performance

- Fixed sign-out leaving music playing or restoring the session on the next launch.
- Stopped background library sync from restoring data after sign-out or carrying the previous account's data into a new login.
- Kept app settings, custom Spotify credentials and the separate Last.fm connection when signing out of Spotify.
- Fixed profile lookup failures leaving a working login reported as failed.
- Reduced startup work by loading stored credentials alongside the database. Bundled Inter locally so startup no longer waits for Google Fonts.
- Reused one HTTP client across authentication, metadata, lyrics and other requests. Added connection pooling, HTTP/2 and compressed responses.
- Added a cached Spotify internal API layer for extended metadata, personalized shelves, artist details, Canvas, credits, folders and radio. Patched the vendored librespot Connect client for Jam commands and queue state.
- Added database migrations for listening history and taste profiles, lyric caches, track ISRCs, YouTube matches and internal metadata caches.
- Batched metadata cache reads and writes, reduced repeated artist lookups and fetched independent library requests in parallel.
- Reduced unnecessary player, track-row, album-card and lyric renders. Playback position updates no longer serialize unchanged settings to storage.
- Shared device and window-focus listeners between consumers, and removed them when the last consumer closes.
- Cached queue membership, sorted page data and artwork colors. Capped persisted stores and the in-memory artwork color cache.
- Fetched cover images at the size they are displayed and avoided duplicate artwork requests.
- Reduced audio resampling, lyric alignment and podcast time-stretching overhead without changing the selected audio quality.
- Reduced YouTube download copies and kept a bounded set of range requests running. Cancelling playback drops pending downloads.
- Reduced metadata, database and playback allocations, including repeated cloning of cached playlist artists and prepared audio.
- Added regression tests and benchmarks for lyrics, resampling, time stretching, downloads, caching, listener cleanup and player updates. Recorded the measured results in PERFORMANCE.md.
- Updated the README, screenshots and bug report template. Added screen recordings to .gitignore.
- Releases now publish the changelog for the tagged version instead of the installation message. The workflow checks version numbers and rejects missing or empty release notes.
