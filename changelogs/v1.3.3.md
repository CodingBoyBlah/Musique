## Sign-in

## Playback

- Made playback controls more responsive and improved seeking for Spotify and YouTube audio.
- Keep the selected official Spotify device when choosing another song in Musique.
- Improved pause, resume, skip and remote playback handling.
- Calculate Spotify listening time from audio consumed by the output, excluding paused silence, seek jumps and discarded buffers. Spotify's Sound Capsule ingestion remains unverified.
- Added documentation for local Spotify playback, official-player control and listening-history limits.

- Keep overlapping backing vocals active alongside the main lyrics.
- Reveal backing vocals with the active lyrics and improve scrolling in the lyrics panel and immersive mode.
- Added a setting for backing-vocal visibility.

## Performance

- Optimized library synchronization, cached data access and playback data paths.
