## Spotify sign-in

- Fix the ncspot redirect configuration error by using its registered `/ncspot_login` callback path.
- Accept the ncspot callback in Musique's local sign-in listener and use the same redirect URI when exchanging the authorization code.
- Preserve `/login` for custom Spotify developer apps and Spotify desktop authorization.
- Add regression checks for redirect selection, callback state validation, cancellation, and completing the two sign-in tabs in either order.
