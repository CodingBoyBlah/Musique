## Spotify Soloist

- Add Spotify Soloist as an optional playback engine. Set it up and turn it on from Settings with your own Soloist key.
- Download Soloist from Spotify on first use, sign it in with the playback account, and restart it if it exits.
- Run Soloist above normal priority on Windows.

## Faster starts and seeks

- Start a song from its first packet, fetch its end along with its start, and request its audio key while the file opens.
- Seek with random access and wait for one second of audio instead of thirty. Read a song's end only when it is first seeked into.
- Count streamed audio as it arrives, and let seeks skip the read-ahead.
- Fetch the last played song ahead of time on a new session, and prefetch upcoming tracks.

## Smoother playback

- Fade audio cuts and keep queued audio when the output device changes.
- Queue the start of a stream before it plays so tracks no longer open with a dropout.
- Start the next track from the engine instead of waiting on the interface, and stop a finished track from cancelling the next load.
- Reopen an audio output that stops without an error, and follow the default device sooner.
- Close the audio output while idle, and walk volume changes to their level instead of stepping.
- Keep a single running copy of Musique so two sessions never compete for the audio device.

## Session recovery

- Reconnect and keep playing when the Spotify session drops mid-song, including a jam's queue.
- Pace audio key requests, stop on refused keys, and bound access point socket setup and handshake packets.
- Play a new song after a pause the player never received.

## Interface

- Build the home speed dial from Spotify's home shortcuts, ranked by what you play, in a grid that adapts to the window width.
- Animate the immersive view with a palette-driven background, fade idle controls, and let lyrics fill the panel.
- Refine lyric typography and spacing, and keep lyrics in time with playback reports.
- Self-host Host Grotesk for the UI.
- Show covers for Spotify-made playlists.
- Answer repeated searches from memory, and request the catalogue and the rest of a search in parallel.
- Keep scrolling and the progress bar smooth while lyrics are being enriched.
- Block browser shortcuts such as reload and find in release builds.

## Engine groundwork

These are in the engine but not yet exposed in Settings:

- Loudness normalisation, a ten-band equalizer, a cubic volume curve, a session proxy, and a local files folder.
- Discovery and sign-in for Spotify Connect, Cast, and Sonos speakers on the network.
